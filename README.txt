مُراجِع V3 — نسخة Full-Stack أولية

التقنية: Python + Flask + SQLite.
المزايا:
- حسابات طلاب حقيقية محفوظة في قاعدة بيانات SQLite.
- تسجيل دخول وخروج للطلاب.
- لوحة تحكم للمدير.
- رفع PDF للمذكرات والملفات.
- إضافة امتحانات PDF.
- إضافة بنك أسئلة.
- تقسيم المواد إلى علمي وأدبي.
- واجهة RTL متجاوبة مع الهاتف.

تشغيل على الكمبيوتر:
1. ثبّت Python 3.11 أو أحدث.
2. افتح Terminal داخل المجلد.
3. نفّذ: pip install -r requirements.txt
4. نفّذ: python app.py
5. افتح: http://127.0.0.1:5000
6. لوحة المدير: http://127.0.0.1:5000/admin
7. كلمة مرور المدير الافتراضية: 123456

مهم قبل النشر:
غيّر ADMIN_PASSWORD وSECRET_KEY في متغيرات البيئة، ولا تترك كلمة المرور الافتراضية.
هذه نسخة بداية وليست إعداد إنتاج نهائي: قبل الإطلاق العام نضيف حماية CSRF، حدود رفع الملفات، إدارة المستخدمين والصلاحيات، نسخ احتياطي، وتخزين ملفات مناسب.
